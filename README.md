 📊 Dashboard de Ventas en Excel

## Introducción

Este proyecto consiste en el desarrollo de un Dashboard interactivo de ventas utilizando Microsoft Excel, con el objetivo de analizar el desempeño comercial de una empresa y transformar los datos en información útil para la toma de decisiones.

A partir de una base de datos de ventas, se realizó la organización y el procesamiento de la información mediante fórmulas, tablas dinámicas y herramientas de análisis de Excel.

El Dashboard permite visualizar y analizar diferentes aspectos del negocio, como el volumen de ventas, los objetivos comerciales, el rendimiento de los vendedores, los productos comercializados y el desempeño de las distintas tiendas.

El propósito principal es facilitar la interpretación de los resultados, identificar tendencias y ofrecer una visión general del comportamiento de las ventas.

## 🎯 Objetivo del proyecto

Aplicar herramientas de análisis y visualización de datos en Excel para desarrollar un reporte dinámico que permita explorar información comercial, realizar comparaciones y obtener conclusiones que contribuyan a la toma de decisiones.

 ## 🛠️ Herramientas utilizadas
 
- Microsoft Excel
- Tablas dinámicas
- Fórmulas
- Gráficos dinámicos
- Segmentadores de datos

## ⚙️ Procesamiento de datos

Para el desarrollo de este proyecto se trabajó con una base de datos de ventas que contiene información sobre fechas, vendedores, tiendas, productos, cantidades comercializadas, precios y metas de ventas.

Se organizó la información en una tabla estructurada de Excel y se incorporaron fórmulas para obtener nuevos campos y facilitar el análisis:

- **Total de ventas:** cálculo del importe total mediante la multiplicación de la cantidad vendida por el precio unitario.
- **Metas de ventas:** cálculo de objetivos comerciales considerando un incremento del 15% sobre el total de ventas.
- **Año:** extracción del año a partir de la fecha de cada operación para facilitar el análisis temporal.

Posteriormente, se utilizaron tablas dinámicas para resumir y analizar la información, permitiendo comparar resultados por vendedor, tienda y producto.

Finalmente, los resultados obtenidos se utilizaron como base para construir un Dashboard interactivo que facilita la interpretación de los datos y la visualización del desempeño comercial.

## 📈 Análisis realizado

A través de este proyecto se realizó un análisis del desempeño comercial, utilizando tablas dinámicas, indicadores y gráficos para facilitar la interpretación de los resultados.

Los principales aspectos analizados fueron:

- **Análisis de ventas:** análisis del total de dinero obtenido por las ventas y comparación con las metas comerciales para evaluar los resultados alcanzados.
- **Cumplimiento de objetivos:** comparación entre los resultados obtenidos y los objetivos comerciales proyectados, considerando un incremento del 15%.
- **Productos más vendidos:** identificación y comparación de los productos con mayores ventas.
- **Rendimiento de vendedores:** comparación de las ventas realizadas por cada vendedor para identificar quiénes alcanzaron los mayores resultados comerciales.
- **Análisis por tiendas:** comparación de la actividad comercial entre las distintas sucursales.
- **Análisis temporal:** organización de las ventas por año para facilitar el seguimiento de la actividad comercial.

El análisis permite obtener una visión general del comportamiento de las ventas, comparar resultados y reconocer los principales factores que intervienen en el desempeño comercial.

## 📷 Dashboard

A continuación, se presenta el Dashboard interactivo desarrollado en Excel, que permite visualizar los principales indicadores de ventas y analizar el desempeño comercial mediante 
gráficos, tablas y segmentadores de datos.

La herramienta facilita la consulta y comparación de resultados por vendedores, productos y tiendas, ofreciendo una visión general de la actividad comercial.
